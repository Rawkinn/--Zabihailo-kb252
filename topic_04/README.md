# Topic 04 — Обробка винятків

`task_1.py` розширює калькулятор із попередньої теми. Програма працює в циклі, а додавання, віднімання, множення та ділення залишаються окремими функціями.

Запуск із кореня репозиторію:

```text
python topic_04/task_1.py
```

Сторонні бібліотеки не потрібні. У репозиторії використовується Python 3.10 або новіший; цей файл не залежить від інших тем.

## Введення даних

Функція `request_data()` запитує перше число, знак операції та друге число. Вона сама обробляє `ValueError`, що виникає під час перетворення неправильного рядка на `float`, і починає новий запит замість аварійного завершення.

Підтримуються операції `+`, `-`, `*`, `/`. Невідома операція також починає новий запит; друге число для неї не запитується. Після помилки введення програма знову запитує перше число. Для десяткових дробів використовуйте крапку.

Команди `exit`, `quit`, `q` та `вихід` працюють на будь-якому запиті. Регістр і пробіли навколо команди не заважають завершенню. `EOFError` (кінець потоку введення) та `KeyboardInterrupt` (Ctrl+C) також обробляються у `request_data()`.

## Ділення на нуль

Функція `divide()` виконує ділення всередині `try` і перехоплює `ZeroDivisionError` власним `except`. При помилці вона друкує пояснення й повертає `None`. Головний цикл не друкує `None` як результат і дозволяє наступне обчислення.

Коректний нульовий результат, наприклад `5 - 5`, друкується як `Результат: 0`: перевіряється `result is not None`, а не істинність числа.

## Приклади

- `8`, `/`, `2` → `Результат: 4`.
- `8`, `/`, `0` → повідомлення про ділення на нуль; далі можна ввести нові дані.
- `abc` → повідомлення про неправильне число; далі повторюється запит першого числа.
- `5`, `-`, `5` → `Результат: 0`.
- `exit` → завершення програми.

## Розглянуті винятки

За [офіційним списком вбудованих винятків Python](https://docs.python.org/3/library/exceptions.html):

- `ValueError` — значення має невідповідний зміст, наприклад `float("abc")`.
- `ZeroDivisionError` — ділення на нуль.
- `EOFError` — `input()` отримує кінець потоку без даних.
- `KeyboardInterrupt` — користувач перериває виконання, зазвичай Ctrl+C. Цей виняток походить від `BaseException`, тому його перехоплено явно.

Завдання зі списком винятків виконано через ознайомлення з документацією та застосування відповідних винятків у калькуляторі. Попередні теми залишено без змін.
