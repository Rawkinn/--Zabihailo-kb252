# Topic 07. Об'єктно-орієнтоване програмування

Тема про класи, об'єкти, методи `__init__` і `__str__`, сортування об'єктів і калькулятор через ООП.

Запуск із кореня репозиторію:

```text
python topic_07/task_2.py
python topic_07/task_3.py
python topic_07/calc.py
```

Сторонні бібліотеки не потрібні. Потрібен Python 3.10 або новіший.

## Завдання 1. Документація класів

Опрацьовано розділ документації Python про класи:

```text
https://docs.python.org/3/tutorial/classes.html
```

Розглянуто створення класу, об'єкти, атрибути, методи, `__init__` і `__str__`. Окремого файлу з кодом немає, бо це теоретичне завдання.

## Завдання 2. Методи `__init__` і `__str__`

У `task_2.py` є клас `Book`. Метод `__init__` приймає назву й автора та зберігає їх в атрибутах. Метод `__str__` повертає рядок, який використовує `print()`.

Приклад:

```text
Тарас Шевченко. Кобзар
Назва: Кобзар
Автор: Тарас Шевченко
```

## Завдання 3. Клас Student

У `task_3.py` клас `Student` має поля `name` і `age`. Створюється список з чотирьох об'єктів. Для сортування використовується `sorted()` з ключем:

```python
sorted(students, key=lambda student: student.name)
```

Початковий список не змінюється. Програма друкує об'єкти в порядку імен.

Приклад:

```text
Андрій, вік: 19
Богдан, вік: 18
Марія, вік: 21
Олена, вік: 20
```

## Завдання 4. Калькулятор через ООП

Код розділено на три файли:

- `calculator.py`: клас `Calculator` з методами `add()`, `subtract()`, `multiply()`, `divide()` і `calculate()`;
- `operations.py`: запит даних `request_data()`;
- `calc.py`: створення об'єкта `Calculator` і головний цикл.

Ділення на нуль піднімає `ZeroDivisionError`, а `calc.py` перехоплює його і показує повідомлення. Команди `exit`, `quit`, `q` і `вихід` завершують роботу.

Приклад:

```text
Перше число: 8
Операція (+, -, *, /): /
Друге число: 2
Результат: 4
```

Файл `calc.py` запускається з кореня репозиторію. Python додає папку скрипта до шляху пошуку модулів, тому `import operations` і `from calculator import Calculator` працюють без додаткових налаштувань.
