# Topic 03 — Цикли, списки та словники

Потрібен Python 3.10 або новіший: перше завдання імпортує калькулятор із `match` з попередньої теми. Сторонні бібліотеки не потрібні.

Запуск із кореня репозиторію:

```text
python topic_03/task_1.py
python topic_03/task_2.py
python topic_03/task_3.py
python topic_03/task_4.py
```

## Завдання 1

Калькулятор працює в циклі `while True` та використовує функцію `calculate()` з `topic_02/task_3.py`. Після результату або помилки програма знову запитує перше число.

Вводьте перше число, операцію `+`, `-`, `*` або `/`, потім друге число. Для завершення на будь-якому запиті введіть `exit`, `quit`, `q` або `вихід`. Великі літери та пробіли навколо команди не заважають завершенню.

Приклад: `8`, `/`, `2` → `Результат: 4`; далі `7`, `*`, `3` → `Результат: 21`; `exit` завершує програму.

Неправильне число, невідома операція та ділення на нуль показують повідомлення про помилку й не переривають наступне обчислення. Для десяткових дробів використовуйте крапку.

## Завдання 2

Програма послідовно демонструє `extend()`, `append()`, `insert()`, `remove()`, `sort()`, `reverse()`, `copy()` та `clear()`. Після кожної операції виводиться список.

Окремо показано, що додавання числа до копії не змінює початковий список. Для вкладених змінюваних об'єктів `copy()` створює поверхневу копію; приклад використовує цілі числа.

## Завдання 3

Програма демонструє оновлення й додавання записів через `update()`, видалення запису оператором `del`, отримання ключів `keys()`, значень `values()`, пар `items()` та очищення словника `clear()`.

`del` є оператором Python, а не функцією словника. Правильний запис: `del marks["Математика"]`.

## Завдання 4

Функція `find_insert_position(sorted_list, value)` шукає позицію вставки власним бінарним пошуком. Вхідний список має бути відсортований за зростанням. Індексація починається з нуля.

Повертається індекс перед першим елементом, не меншим за нове значення. Якщо значення вже є у списку, вставка відбувається перед однаковими елементами. Порожній список дає позицію `0`, найбільше нове значення — позицію `len(sorted_list)`.

Демонстрація працює зі списком `[1, 3, 5, 7, 9]`. Введення `6` дає позицію `3` та список `[1, 3, 5, 6, 7, 9]`. Пошук позиції не змінює початковий список; вставку окремо виконує `insert()` у демонстрації.
