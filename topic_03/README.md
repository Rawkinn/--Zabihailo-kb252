# Topic 03: Цикли, списки та словники

Потрібен Python 3.10 або новіший, бо перше завдання імпортує калькулятор з `match` з попередньої теми. Сторонні бібліотеки не потрібні.

Запускати з кореня репозиторію:

```text
python topic_03/task_1.py
python topic_03/task_2.py
python topic_03/task_3.py
python topic_03/task_4.py
```

## Завдання 1

Калькулятор працює в циклі `while True` і використовує `calculate()` з `topic_02/task_3.py`. Після результату або помилки він знову питає перше число.

Спочатку вводимо перше число, потім операцію `+`, `-`, `*` або `/`, а потім друге число. Щоб вийти, на будь-якому запиті можна ввести `exit`, `quit`, `q` або `вихід`. Великі літери і пробіли навколо команди не заважають.

Наприклад, `8`, `/`, `2` дає `Результат: 4`; далі `7`, `*`, `3` дає `Результат: 21`; `exit` завершує програму.

Якщо число неправильне, операція невідома або ділення на нуль, програма показує помилку і далі можна рахувати. Дробові числа пишемо з крапкою.

## Завдання 2

Програма по черзі показує `extend()`, `append()`, `insert()`, `remove()`, `sort()`, `reverse()`, `copy()` і `clear()`. Після кожної дії друкується список.

Окремо видно, що додавання числа до копії не змінює початковий список. Для вкладених змінних об'єктів `copy()` робить поверхневу копію, але в прикладі використовуються цілі числа.

## Завдання 3

Програма показує, як оновлювати і додавати записи через `update()`, видаляти запис через `del`, отримувати ключі `keys()`, значення `values()`, пари `items()` і очищати словник через `clear()`.

`del` це оператор Python, а не метод словника. Правильно писати так: `del marks["Математика"]`.

## Завдання 4

Функція `find_insert_position(sorted_list, value)` сама шукає місце для вставки бінарним пошуком. Список має бути відсортований за зростанням. Індекси починаються з нуля.

Функція повертає індекс перед першим елементом, який не менший за нове значення. Якщо таке значення вже є, вставка буде перед однаковими елементами. Для порожнього списку буде `0`, а для найбільшого значення `len(sorted_list)`.

У прикладі є список `[1, 3, 5, 7, 9]`. Якщо ввести `6`, позиція буде `3`, а список стане `[1, 3, 5, 6, 7, 9]`. Пошук не змінює список, вставку робить окремий `insert()`.
