# Topic 02 — Умовні конструкції

Для запуску потрібен Python 3.10 або новіший, оскільки третє завдання використовує `match`.

Запуск із кореня репозиторію:

```text
python topic_02/task_1.py
python topic_02/task_2.py
python topic_02/task_3.py
```

Можна також відкрити потрібний файл у VS Code та запустити його кнопкою Run Python File.
Сторонні бібліотеки не потрібні.

## Завдання 1

`task_1.py` знаходить дійсні корені рівняння `ax² + bx + c = 0`.
Функція `get_roots(a, b, c)` використовує `get_discriminant()` із попередньої теми — `topic_01/task_3.py`.

- `D > 0`: два корені;
- `D = 0`: один корінь;
- `D < 0`: дійсних коренів немає;
- `a = 0`: повідомлення про помилку, оскільки рівняння не є квадратним.

Приклад: `a = 1`, `b = -3`, `c = 2` → `D = 1`, корені `2` і `1`.

## Завдання 2

`task_2.py` — калькулятор на `if/elif/else`. Додавання, віднімання, множення та ділення реалізовані в окремих функціях.
Програма запитує перше число, знак операції та друге число.

Приклад: `8`, `/`, `2` → `Результат: 4`.

## Завдання 3

`task_3.py` — калькулятор на `match/case` з окремими функціями для кожної операції.

Приклад: `7`, `*`, `3` → `Результат: 21`.

Обидва калькулятори повідомляють про ділення на нуль, невідому операцію та неправильне введення числа.
Для десяткових дробів використовуйте крапку: `2.5`.
