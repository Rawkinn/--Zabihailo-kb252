Для запуску потрібен Python 3.10 або новіший, бо в третьому завданні використовується `match`.

Запускати треба з кореня репозиторію:

python topic_02/task_3.py

Можна також відкрити файл у VS Code і натиснути Run Python File.
Сторонні бібліотеки не потрібні.

## Завдання 1

`task_1.py` шукає дійсні корені рівняння `ax² + bx + c = 0`.
Функція `get_roots(a, b, c)` бере `get_discriminant()` з попередньої теми, тобто з `topic_01/task_3.py`.

- `D > 0`: буде два корені;
- `D = 0`: буде один корінь;
- `D < 0`: дійсних коренів немає;
- `a = 0`: програма пише помилку, бо рівняння вже не квадратне.

Наприклад, якщо `a = 1`, `b = -3`, `c = 2`, то `D = 1`, а корені `2` і `1`.

## Завдання 2

`task_2.py` це калькулятор на `if/elif/else`. Додавання, віднімання, множення і ділення зроблені окремими функціями.
Програма по черзі питає перше число, знак операції і друге число.

Наприклад, `8`, `/`, `2` дає `Результат: 4`.

## Завдання 3

`task_3.py` це такий самий калькулятор, але на `match/case`. Для кожної операції теж є окрема функція.

Наприклад, `7`, `*`, `3` дає `Результат: 21`.

Обидва калькулятори пишуть про помилку, якщо ділити на нуль, ввести невідому операцію або неправильне число.
Дробові числа треба вводити з крапкою: `2.5`.
