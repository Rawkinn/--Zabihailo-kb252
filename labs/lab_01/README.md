# Лабораторна робота 1

Телефонний довідник студентів із чотирма полями: ПІБ, телефон, email та група.

## Запуск

Із кореня репозиторію:

```text
python labs/lab_01/lab_01.py
```

Або відкрийте папку `labs/lab_01` і виконайте `python lab_01.py`.
Потрібен Python 3.10 або новіший. Сторонні бібліотеки не потрібні.

## Меню

- `1` — додати студента;
- `2` — змінити вибраний запис;
- `3` — видалити вибраний запис;
- `4` — показати довідник;
- `0` — завершити роботу. Також підтримуються `q`, `exit`, `вихід`.

Для зміни та видалення спочатку показується таблиця. Введіть номер запису
з першого стовпця; нумерація починається з 1. Однакові ПІБ дозволені,
оскільки записи вибираються за номером, а не за ім’ям.

Під час додавання або зміни введіть `/cancel` у будь-якому полі, щоб
скасувати всю операцію. Та сама команда працює під час вибору номера.
Під час зміни порожнє введення зберігає поточне значення поля.
Під час додавання всі чотири поля мають бути непорожніми.

## Структура даних та сортування

Довідник — список словників із ключами `name`, `phone`, `email`, `group`.
Назви полів збережені в кортежі `FIELDS`. Телефон залишається рядком,
тому початковий нуль і знак `+` не втрачаються.

Записи впорядковані лексикографічно за `name.casefold()`, без урахування
регістру. Це порядок рядків Python, а не окреме налаштування української
локалі. Новий запис з однаковим ПІБ додається після наявних рівних імен.

`edit_student()` спочатку перевіряє нові дані, потім викликає
`delete_student()` та `add_student()`. Тому після зміни ПІБ запис займає
нову відсортовану позицію. Помилка перевірки або скасування не видаляє
початковий запис. Вхідні словники копіюються.

Дані зберігаються в пам’яті лише протягом поточного запуску; після виходу
довідник не записується у файл. Перевіряється наявність усіх полів,
а не повний формат телефону або email. Навчальні приклади у звіті
не є реальними контактами студентів.

Код реалізовано з нуля, оскільки стартовий `lab_01.py`, згаданий у
методичних вказівках, не був наданий. Окремий звіт розміщено поруч із кодом.
