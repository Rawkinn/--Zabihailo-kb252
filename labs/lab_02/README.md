# Лабораторна робота 2

Телефонний довідник із завантаженням і збереженням CSV та юніт-тестами.
Операції над записами й введення чотирьох полів повторно використовуються
з `labs/lab_01/lab_01.py`; перша лабораторна не змінюється.

## Запуск

Із кореня репозиторію:

```text
python labs/lab_02/lab_02.py labs/lab_02/lab2.csv
```

Ім’я CSV є обов’язковим аргументом командного рядка. Для шляху з пробілами
використовуйте лапки. Програма може запускатися з будь-якої папки, якщо
вказано правильні шляхи до скрипту та CSV.

Наведений приклад змінює переданий `lab2.csv` після виходу. Щоб залишити
навчальний приклад незмінним, спочатку зробіть його копію та передайте
шлях до копії. Дані у прикладі вигадані, адреси використовують example.com.

Потрібен Python 3.10 або новіший. Для самої програми сторонні бібліотеки
не потрібні; репозиторій має містити також папку `labs/lab_01`.

## Формат CSV

Обов’язкові чотири стовпці: `name`, `phone`, `email`, `group`.
Порядок стовпців може відрізнятися, регістр і пробіли в заголовках
не враховуються. Підтримується UTF-8 з BOM або без нього. Роздільник — кома.
Значення з комами та лапками обробляє модуль `csv`.

Телефон залишається рядком: знак `+` і початкові нулі зберігаються.
Усі поля мають бути непорожніми. Довідник сортується за `name.casefold()`.
CSV лише із заголовком означає порожній довідник. Зовсім порожній файл,
пошкоджені рядки або неправильні заголовки спричиняють повідомлення про
помилку; такий файл не перезаписується. Відсутній файл не створюється
автоматично: можна підготувати CSV лише з правильним заголовком.

## Меню та збереження

Меню з першої лабораторної збережено: `1` — додати, `2` — змінити,
`3` — видалити, `4` — показати, `0` — вийти. Також працюють `q`, `exit`,
`вихід`. Записи вибираються за номером; однакові ПІБ дозволені.
`/cancel` скасовує операцію, порожнє поле під час зміни зберігає значення.

Перед нормальним виходом, EOF або Ctrl+C у меню дані записуються назад
у той самий CSV. Для сумісності з кирилицею в Excel результат має UTF-8 BOM.
Спочатку перевіряються всі записи та створюється тимчасовий файл поруч,
потім він замінює попередній CSV. Помилка перевірки або запису не обрізає
існуючий файл. Якщо збереження не вдалося, програма повідомляє про це
та завершується з кодом помилки.

## Юніт-тести

Встановлення тестової залежності та запуск із кореня репозиторію:

```text
python -m pip install -r labs/lab_02/requirements-dev.txt
python -m pytest labs/lab_02/test_lab_02.py -q
```

Тести використовують тимчасові файли. Вони не змінюють навчальний CSV
та перевіряють додавання, зміну, видалення, сортування, читання/запис,
помилки даних і збереження перед виходом.

Окремий звіт `zvit_lab_02.docx` розміщено поруч із кодом.

Документація: [csv](https://docs.python.org/3/library/csv.html),
[open](https://docs.python.org/3/library/functions.html#open),
[pytest](https://docs.pytest.org/en/stable/).
