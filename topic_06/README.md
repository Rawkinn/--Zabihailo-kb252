# Topic 06. Робота з файлами

Тема про файли, дописування даних і сортування колекцій. У папці дві програми: калькулятор із логуванням і сортування списку словників.

Запуск із кореня репозиторію:

```text
python topic_06/calc.py
python topic_06/task_2.py
```

Сторонні бібліотеки не потрібні. Потрібен Python 3.10 або новіший.

## Завдання 1. Логування калькулятора

Калькулятор перенесено з теми 5. Файли `functions.py`, `operations.py` і `calc.py` лежать у папці `topic_06`. Після кожного обчислення `calc.py` додає рядок у файл `calc.log`.

Функція `write_log()` відкриває файл у режимі дописування `"a"` з кодуванням `utf-8` і записує дату, перше число, операцію, друге число та результат. Шлях до файлу будується через `Path(__file__)`, тому лог створюється поруч із `calc.py`, навіть якщо запускати програму з кореня репозиторію.

Приклад вмісту `calc.log`:

```text
[24.11.2026 17:58:14] 8 / 2 = 4
[24.11.2026 17:58:14] 5 - 5 = 0
[24.11.2026 17:58:14] 8 / 0 = помилка: ділення на нуль
```

Ділення на нуль не завершує програму. Помилка теж потрапляє у лог. Команди `exit`, `quit`, `q` і `вихід` завершують роботу.

## Завдання 2. Сортування списку словників

У `task_2.py` є невідсортований список `students`. Кожен елемент це словник з полями `name` і `grade`. Функція `sorted()` повертає новий список, а параметр `key` отримує `lambda`.

Сортування за ім'ям:

```python
by_name = sorted(students, key=lambda student: student["name"])
```

Сортування за оцінкою:

```python
by_grade = sorted(students, key=lambda student: student["grade"])
```

Початковий список не змінюється. Програма друкує обидва відсортовані списки.

Приклад:

```text
За іменем:
{'name': 'Андрій', 'grade': 75}
{'name': 'Богдан', 'grade': 75}
{'name': 'Марія', 'grade': 88}
{'name': 'Олена', 'grade': 90}
{'name': 'Петро', 'grade': 95}
За оцінкою:
{'name': 'Андрій', 'grade': 75}
{'name': 'Богдан', 'grade': 75}
{'name': 'Марія', 'grade': 88}
{'name': 'Олена', 'grade': 90}
{'name': 'Петро', 'grade': 95}
```
