# Технології програмування — КБ-252

Практичні завдання Кирила Забігайла з мови Python.

- `topic_00` — пробний запуск Git.
- `topic_01` — рядки, методи рядків і дискримінант.
- `topic_02` — корені квадратного рівняння та калькулятори з `if/else` і `match`.
- `topic_03` — калькулятор із циклом, методи списків і словників та пошук позиції вставки.
- `topic_04` — калькулятор з обробкою винятків під час введення та ділення.
- `TP-KB-252-Kirill-Zabihailo-lpr.docx` — спільний звіт до тем 1, 2, 3 і 4.

Для Topic 02 і Topic 03 потрібен Python 3.10 або новіший. Сторонні бібліотеки не потрібні.

Запуск із кореня репозиторію:

```text
python topic_02/task_1.py
python topic_02/task_2.py
python topic_02/task_3.py
```
