# Topic 05. Бібліотеки

Тема про модулі, пакети і сторонні бібліотеки. У папці три програми: гра з модулем `random`, конвертер валют через API НБУ і калькулятор, розділений на модулі.

Запуск із кореня репозиторію:

```text
python topic_05/task_1.py
python topic_05/task_2.py
python topic_05/calc.py
```

Для конвертера потрібен пакет `requests`:

```text
python -m pip install -r topic_05/requirements.txt
```

Інші програми сторонніх бібліотек не потребують. Потрібен Python 3.10 або новіший.

## Завдання 1. Гра «камінь, ножиці, папір»

Програма запитує один із варіантів: `stone`, `scissor` або `paper`. Комп'ютер вибирає варіант випадково через `random.choice()`. Регістр і пробіли навколо відповіді не мають значення.

Функція `get_result()` перевіряє три виграшні комбінації: камінь проти ножиць, ножиці проти паперу, папір проти каменю. Якщо варіанти однакові, це нічия. В інших випадках перемагає комп'ютер.

Для завершення введіть `exit`, `quit`, `q` або `вихід`. Неправильне значення не закриває гру, а повторює запит.

Приклад:

```text
Ваш вибір (stone, scissor, paper): stone
Вибір комп'ютера: scissor
Ви перемогли!
```

## Завдання 2. Конвертер валют

Курси беруться з API Національного банку України:

```text
https://bank.gov.ua/NBUStatService/v1/statdirectory/exchange?json
```

Запит виконує бібліотека `requests`. З відповіді вибираються курси `EUR`, `USD` і `PLN`. Поле `rate` показує, скільки гривень коштує одна одиниця валюти. Результат рахується просто: сума множиться на курс.

Введіть додатну суму і код валюти. Після результату можна зробити ще одне перетворення. Команди `exit`, `quit`, `q` і `вихід` завершують роботу.

Приклад:

```text
Курси НБУ:
EUR: 49.606 грн
USD: 45.3541 грн
PLN: 11.1164 грн
Сума: 100
Валюта (EUR, USD, PLN): USD
100 USD = 4535.41 грн
```

Курси змінюються щодня, тому числа у прикладі можуть бути іншими. Якщо API недоступне, програма показує повідомлення про помилку і завершується. Неправильна сума або непідтримувана валюта повторює відповідний запит.

## Завдання 3. Калькулятор із модулів

Код розділено на три файли в папці `topic_05`:

- `functions.py`: функції `add()`, `subtract()`, `multiply()` і `divide()`;
- `operations.py`: запит даних `request_data()` і вибір операції `calculate()`;
- `calc.py`: головний цикл програми.

`operations.py` підключає `functions.py`, а `calc.py` підключає `operations.py`. Функція `divide()` піднімає `ZeroDivisionError`, а `calc.py` перехоплює його і показує повідомлення. Неправильне число або невідома операція повторює запит.

Приклад:

```text
Перше число: 8
Операція (+, -, *, /): /
Друге число: 2
Результат: 4
```

Файл `calc.py` запускається з кореня репозиторію. Python додає папку скрипта до шляху пошуку модулів, тому `import operations` працює без додаткових налаштувань.
